# DropFour

Four-bar live drop desk for bedroom producers and AI-music finishers.

Suno and loop DAWs ride the lift and never land. Session players write four live bars where the kick returns, the filter opens, and the bass takes the floor.

Audio never leaves the tab. Live FluidR3 chairs + kit from the PreEight sample bank. No oscillators.

## Devices

Because this desk makes noise, it asks for:

- **Audio input** — optional live mic / interface into the same filter bus
- **Audio output** — `setSinkId` when the browser allows it
- **MIDI controller** — pads 36/38/42/49 hit kit; CC1 sweeps the drop filter; note 60 fires Drop only

Chrome / Edge for Web MIDI and output routing. Allow the mic prompt so device labels appear.
